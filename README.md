#### Quality Notice

Generally speaking, this is not professional work.  This is a personal set of
repositories where I am chasing whatever whimsy appeals.

As exclusions to the above, the following repositories are known to be in
production, or otherwise receiving above-average attention:

- [devproxy2](https://github.com/sapphirecat/devproxy2);
  for toolchain reasons, a predecessor _exists,_ but it is abandonware.
- [dynacache](https://github.com/sapphirecat/dynacache), though source is
  unavailable for political reasons
- [quilt-draw](https://github.com/sapphirecat/quilt-draw) and its
  [stable release](https://sapphirecat.github.io/quilt-draw)

There is no support guarantee, but they are _more_ likely to be proactively
updated if they break.

#### Vim Themes and Things

My Vim colorschemes:

- 🌱 [Garden](https://github.com/sapphirecat/garden-vim),
  an earthy, mid-dark colorscheme
- 🧜 [Zora](https://github.com/sapphirecat/zora-theme-vim),
  based on screenshots of Zora’s Domain in The Legend of Zelda: Breath of the Wild
- 🐈‍⬛ [Feline Soul](https://github.com/sapphirecat/feline-soul-vim),
  a gentle modification of Vim’s `default` theme
- 🌾 [Ashgren](https://github.com/sapphirecat/ashgren-gvim),
  an abandoned experimental green-based theme for GVim only

Plugins:

- 🐘 [PSR-2](https://github.com/sapphirecat/php-psr2-vim)
  automatically sets up indent settings when editing PHP files
- 💾 [BlurSave](https://github.com/sapphirecat/blursave-vim)
  saves all open files when GVim loses focus
- ↔️  [Indent Commands](https://github.com/sapphirecat/indent-cmds-vim)
  offers `:IndentSpace` and similar commands to set tabbing and shiftwidth together,
  like `:IndentTab 2` (all TAB characters, visually 2 spaces)
  or `:IndentMix 4` (4 spaces per level, 8-spaces as TAB characters)
